## 👨‍💻 About me

I’m a software engineer focused on building scalable backend systems, modern web applications, and machine learning powered products.

My work spans:
- **Backend engineering** with FastAPI, Python, Java, PHP, and distributed services
- **Frontend development** with ReactJS, JavaScript, HTML/CSS, and modern web architecture
- **Machine learning systems** using PyTorch, OpenCV, NLP, and real-time inference pipelines
- **Cloud and infrastructure** across AWS, GCP, Docker, Kubernetes, Redis, and Linux
- **Performance and reliability** through concurrency, caching, testing, and low-latency design
